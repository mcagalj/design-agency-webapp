# Building Your Application

Implementing registration and login functionality using [**Better Auth**](https://www.better-auth.com/) authentication framework. For a Next.js application, we will follow the steps shown in [**Next.js integration**](https://www.better-auth.com/docs/integrations/next).

> If you want to understand authentication process with Next.js in detail, check out [**How to implement authentication in Next.js**](https://nextjs.org/docs/app/guides/authentication).
